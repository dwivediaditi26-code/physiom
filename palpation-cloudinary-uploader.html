PhysioMind — Palpation Cloudinary Photo Uploader

3 photo slots per structure (e.g. attachments diagram / starting position / technique close-up) across all 118 Palpation study-library structures — pick a file for each slot you have, then upload. Public IDs match each structure's id in src/palpationData.js (base id, base id + "_2", base id + "_3"), so once uploaded these can be dropped straight into that file's images: [...] arrays.
Needs an unsigned upload preset — Cloudinary won't accept direct browser uploads with your API secret. In your Cloudinary console: Settings → Upload → Upload presets → Add upload preset, set Signing Mode: Unsigned, save, paste its name above. Settings are remembered in this browser for next time.
